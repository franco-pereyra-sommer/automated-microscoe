__________________________________________________________________________________________

Sí. Con [Pixi](https://pixi.sh?utm_source=chatgpt.com) podés crear environments de Python bastante fácil.
Te muestro el flujo básico.

## 1. Crear un proyecto Pixi

En una terminal:

```bash
pixi init mi_proyecto
```

Eso crea una carpeta con un archivo `pixi.toml`.

Entrás a la carpeta:

```bash
cd mi_proyecto
```

---

## 2. Agregar Python

Para instalar la versión más reciente disponible:

```bash
pixi add python
```

Si querés explícitamente Python 3.13 por ejemplo:

```bash
pixi add "python>=3.13"
```

---

## 3. Agregar pyserial

La librería correcta es:

```python
import serial
```

pero el paquete que se instala se llama:

```bash
pyserial
```

Entonces:

```bash
pixi add pyserial
```

---

## 4. Sobre `time`

`time` NO se instala porque viene incluido en la librería estándar de Python.

O sea:

```python
import time
```

funciona automáticamente.

---

## 5. Ejecutar Python dentro del environment

Podés abrir un shell del environment:

```bash
pixi shell
```

Y ahí:

```bash
python
```

o correr scripts:

```bash
python main.py
```

---

## 6. Alternativa rápida: todo junto

Podés crear todo de una:

```bash
pixi init mi_proyecto
cd mi_proyecto
pixi add python pyserial
```

---

## 7. Cómo queda el `pixi.toml`

Algo así:

```toml
[project]
name = "mi_proyecto"
channels = ["conda-forge"]
platforms = ["win-64"]

[dependencies]
python = "*"
pyserial = "*"
```

---

## 8. Tu primer script

`main.py`

```python
import serial
import time

print("Hola")

time.sleep(1)

ser = serial.Serial("COM3", 115200)

ser.write(b"M115\n")

respuesta = ser.readline()

print(respuesta)
```

---

## 9. Ejecutarlo

```bash
pixi run python main.py
```

o entrando antes al shell:

```bash
pixi shell
python main.py
```

---

## 10. Ver paquetes instalados

```bash
pixi list
```

---

## 11. Borrar el environment

Simplemente borrás la carpeta `.pixi`.

```bash
rm -rf .pixi
```

(en Windows la borrás normalmente o usando PowerShell)

```powershell
Remove-Item -Recurse -Force .pixi
```

## Cómo hacer que VSCode detecte el environment de Pixi

### 1. Crear una carpeta de proyecto

Por ejemplo:

```powershell
mkdir C:\Users\Franco\Desktop\impresora3d
cd C:\Users\Franco\Desktop\impresora3d
```

---

### 2. Inicializar Pixi ahí

```powershell
pixi init
pixi add python pyserial
```

Eso crea:

```text
impresora3d/
│
├── pixi.toml
├── .pixi/
└── ...
```

---

### 3. Abrir ESA carpeta en VSCode

Muy importante:

```powershell
code .
```

o desde VSCode:

```text
File → Open Folder
```

y elegís `impresora3d`.

---

### 4. Seleccionar el intérprete

En VSCode:

```text
Ctrl + Shift + P
```

y escribís:

```text
Python: Select Interpreter
```

Ahí debería aparecer algo tipo:

```text
.pixi\envs\default\python.exe
```

Lo seleccionás.

---

## Si NO aparece automáticamente

Podés seleccionarlo manualmente.

El intérprete suele estar en:

```text
<tu proyecto>\.pixi\envs\default\python.exe
```

Por ejemplo:

```text
C:\Users\Franco\Desktop\impresora3d\.pixi\envs\default\python.exe
```

En VSCode:

```text
Python: Select Interpreter
→ Enter interpreter path
→ Browse
```

y elegís ese `python.exe`.

---

## Cómo verificar que funciona

En la terminal integrada de VSCode:

```python
import serial
print("ok")
```

Si no tira error, ya está bien configurado.

---

## Recomendación importante

La estructura típica queda así:

```text
mi_proyecto/
│
├── main.py
├── pixi.toml
├── .gitignore
└── .pixi/
```

y abrís SIEMPRE la carpeta raíz del proyecto en VSCode.
No abras directamente `.pixi` ni `System32`.
